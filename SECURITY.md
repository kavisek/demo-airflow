# Security Policy

## Reporting a vulnerability

Please **don't** open a public issue for security problems.

Report them privately through GitHub: go to the **Security** tab of this repository and click **Report a vulnerability**. Include the affected version, steps to reproduce, and the impact you expect.

You can expect an acknowledgement within 7 days and a fix or mitigation plan within 30 days. Once a fix is released, we'll credit you in the release notes unless you'd rather stay anonymous.

## Supported versions

This is a demo for local use only. Only the current `main` branch receives fixes. The Docker Compose setup turns authentication off on purpose (see the README), so that by itself is not a vulnerability.
